# WBNextlevel Portfolio Website

Static portfolio and lead-generation website for WBNextlevel, a remodeling and home improvement company in Florida.

## Files

- `index.html` - page content, SEO tags, sections, and estimate form
- `styles.css` - responsive layout, colors, spacing, and animations
- `script.js` - mobile menu, scroll effects, reveal animations, and demo form message
- `assets/` - lightweight placeholder images

## How to Run Locally

Open `index.html` in a browser.

No build step, framework, or server is required.

## Before Publishing

- Replace every placeholder SVG in `assets/` with real WBNextlevel project photos.
- Connect the estimate form to email, a CRM, or a form service.
- Add the real phone number, business email, website URL, Google Business Profile, and social links.
- Update the structured data in `index.html` with real contact information when available.
